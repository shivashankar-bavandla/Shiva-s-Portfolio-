DeepFake Audio Detection Using Deep Learning

A Python-based academic project using MFCC audio features and a hybrid CNN-LSTM model to classify real and fake audio.

01Project Overview

A deep learning-based project focused on detecting manipulated or fake audio content by analysing audio characteristics and identifying patterns that may indicate synthetic or altered speech. A web interface allows a user to upload an audio file and view a detection result.

02Problem Statement

Synthetic and manipulated speech can be difficult to distinguish from genuine recordings by listening alone. This project explores an automated classification approach to help identify potentially fake audio.

03Project Objectives

  • Work with real and fake audio samples.
  • Extract MFCC features from audio.
  • Use a hybrid CNN-LSTM deep learning model for classification.
  • Provide a web interface for audio upload and detection results.
